Este repositório contém alguns códigos que fiz como atividade de um dos módulos do curso.

1° Calculos - este calcula a soma, multiplicação, divisão e subtração entre dois números que o usuário colocar.
2° Comparação - Este compara os dois números que o usuário inserir e diz quem é o maior e o menor entre os dois
3° Fatorial - Este exibe a fatorial do número que o usuário inserir.
4° ParOuImpar - Este verifica se o número inserido pelo usuário é par ou impar.
5° PosiOrNega - Este verifica se o número inserido pelo usuário é positivo ou negativo.
6° Tabuada - Este exibe as tabuadas de 1 a 10 do número inserido pelo usuário.
